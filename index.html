Frequently Asked Questions

Questions & Answers

Everything you need to know about ThreatHawk’s privacy model, licensing, and tools.

What is ThreatHawk?

ThreatHawk is an open-source browser-based cybersecurity platform offering password auditing, URL inspection, hash analysis, security log analysis, and data encoding and decoding tools that run directly in your browser without requiring software installation.

Is ThreatHawk free and open source?

Yes. Every tool on ThreatHawk is 100% free under the permissive MIT License. Anyone can review the source code, contribute improvements, report issues, or contribute tools via GitHub.

Is my data uploaded to your servers?

No. ThreatHawk tools operate on a local-first philosophy. Your passwords, hashes, logs, and encoded strings are parsed in your browser’s local memory and are never transmitted to ThreatHawk servers. For URL reputation lookups, only the submitted URL is evaluated against the Google Safe Browsing API.

Who is ThreatHawk built for?

ThreatHawk is designed for cybersecurity students, SOC analysts, penetration testers, incident responders, blue teams, researchers, and developers who need swift, reliable security utilities.

Which browsers are supported?

ThreatHawk supports all modern standards-compliant web browsers including Google Chrome, Mozilla Firefox, Microsoft Edge, Brave, Apple Safari, and Chromium-based browsers.
